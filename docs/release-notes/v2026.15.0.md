# v2026.15.0 — release notes

## 0. One sentence — what this release is

**Four documents that used to parse now throw.** The TOML and YAML readers accepted input their own
specifications forbid, and in three of the four cases they accepted it *quietly* — producing a value, or a
member name, that nobody wrote. That is a behaviour change, so this is `x+1` even though no public API moved.

Everything else in this release is fences: a second ablation wave found 12 more protections no test was
watching, and they are all covered now.

## 1. The four behaviour changes

| # | Input | Before | Now |
|---|---|---|---|
| 1 | TOML `A = 1` then `A = 2` | two `PropertyName(A)` tokens, **the second value silently won** | `FormatException` |
| 2 | YAML tab indentation, `a:` then `\tb: 1` | parsed, with a **root member literally named `"\tb"`** | `FormatException` |
| 3 | YAML unterminated quoted scalar, `A: "oops` | value `oops` | `FormatException` |
| 4 | YAML invalid escape, `A: "x\qy"` | value `xqy` — **the backslash was dropped** | `FormatException` |

**Why these are bugs and not leniency** — the arbiter is the standard, shown through a conforming
implementation (`AGENTS.md`):

| # | Clause | Independent implementation |
|---|---|---|
| 1 | TOML 1.0 §Keys: "defining a key multiple times is invalid" | `tomllib` and Tomlyn both refuse it |
| 2 | YAML 1.2 §6.1: indentation is `s-space × n`; a tab is a separation character | PyYAML: *"found character '\t' that cannot start any token"* |
| 3 | YAML 1.2 §7.3.1/7.3.2: a quoted scalar is delimited by its closing quote | PyYAML: *"while scanning a quoted scalar"* |
| 4 | YAML 1.2 §5.7: the escape set is closed | PyYAML; and `json.loads` reports *"Invalid \escape"* |

**Migration.** A YAML or TOML file that relied on any of the four will now throw. If you have one:

- a **duplicate TOML key** was already ambiguous — the second value won by accident. Keep one.
- a **tab-indented YAML** document was never valid YAML; no conforming parser accepted it. Re-indent with
  spaces.
- an **unterminated quote** or an **unknown escape** in YAML was being repaired for you (the quote closed at
  end of document, the backslash dropped). Fix the document; the value you were reading was not the text in
  the file.

**Not changed, on purpose:** TOML **table** redefinition (`[T]` twice) is also invalid TOML and is still
accepted — it is a separate dedupe and is recorded rather than half-done. INI **duplicate sections and keys**
are still accepted: INI has no specification, and the de-facto standard splits (`configparser` with
`strict=True` refuses, `git config` allows multivar), so no verdict is claimed either way.

## 2. The fences

| Area | What nobody was watching |
|---|---|
| MsgPack | the `fixarray` ceiling (15 elements must be `9F`, 16 must be `DC 00 10`); a negative string length; the timestamp extension tag (only a generated-code snapshot caught it) |
| TOML | the quote-aware bracket scan in a non-final block; the unterminated-literal-key message (the old assertion was satisfied by a neighbouring check) |
| INI | the unterminated-section throw (the value side had such a test, the section side did not) |

## 3. The suite can now be run twice at once

Multi-targeting turned two latent assumptions into a flaky suite. `dotnet test` runs every target framework
as its own **process**, so a nested `dotnet build` of the probe project and a fixed temp file name were
shared state between two processes — `[NotInParallel]` cannot help, it serialises tests *inside* one process.

The nested rebuild now takes a cross-process lock (a named lock file with a timeout, not a `Mutex`, so it
behaves the same on every OS), the streaming test's temp file carries instance identity, and the lock is
itself pinned by tests that report their own breakage — including the case where the holder dies.

## 5. Ablation, second wave

78 mutations across two waves: **53 red, 25 green**, and every green is now either closed or recorded.
`AGENTS.md` gained a section on the method, including the three ways it lies (a filtered run misreports a
watched protection as a hole; `--no-build` keeps a reverted mutation alive; a hole needs a proposed
assertion, not a shrug).
